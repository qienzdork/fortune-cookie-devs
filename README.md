# Fortune Cookie Wisdom for Developers

A tiny deterministic program that writes one original fortune-cookie line
for a software developer to `/output/entry.txt` (or `$OUTPUT_PATH` when set):

> The bug you cannot reproduce is teaching you patience; the one you can is teaching you humility.

Stdlib only, no randomness, no network — the same line every run.
